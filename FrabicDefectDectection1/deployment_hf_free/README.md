# FabricAI Fabric Inspection Preview

This is the free static preview of the FabricAI dashboard. It supports the
dashboard layout and local image preview. It does **not** run the YOLOv8 or
MobileNetV2 models because a Static Space does not run a backend server.

For live inspection, use the full local project with its FastAPI backend. A
public hosted inference version requires a compute-enabled host.
